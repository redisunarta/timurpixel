# timurpixel.com

Static site for Timur Pixel apps, served by GitHub Pages.

- `/` — studio landing page
- `/melekwoy/` — Melek Woy! support page
- `/melekwoy/privacy.html` — Melek Woy! privacy policy (App Store Privacy Policy URL)

To add an app: create `/<appname>/index.html` + `/<appname>/privacy.html` and link it from `index.html`.
